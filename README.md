# Heart Disease Analysis Dashboard – Power BI

An interactive **Power BI dashboard** developed to analyze heart disease data and identify important health patterns and risk factors.

## 📊 Project Overview

This project analyzes patient health data to explore heart disease patterns, patient characteristics, and key health indicators using interactive Power BI visualizations.

## 🛠️ Tools Used

- Power BI
- Power Query
- DAX
- Data Visualization

## 🔍 Key Analysis

- Heart Disease Distribution
- Patient Demographics
- Age and Gender Analysis
- Health Risk Factors
- Key Health Indicators
- Interactive Filters and KPIs

## 📈 Dashboard Features

- Interactive KPI cards
- Dynamic charts
- Slicers and filters
- Patient and risk-factor analysis
- User-friendly dashboard

## 💡 Key Outcome

The dashboard converts health data into meaningful visual insights to support better understanding of heart disease patterns.
